# Contributing

Thanks for helping improve `tart`.

## Before you start

- Open an issue for larger changes before you spend time on implementation.
- Keep pull requests focused on one change when possible.
- Match the existing style of the repo, especially in the Electron desktop code and shell scripts.

## Local setup

```bash
npm install
npm run test:desktop
```

For a full check, you can also run:

```bash
npm test
```

## Good contributions

- Bug fixes
- Small UX improvements
- Better docs
- Tests for desktop behavior or CLI behavior
- Packaging and release improvements

## What to include in a pull request

- A short summary of the change
- Why the change is needed
- Any testing you ran
- Screenshots or screen recordings for UI changes when helpful

## Notes

- Please avoid unrelated refactors in the same pull request.
- If you change the desktop UI, update the tests alongside it.
